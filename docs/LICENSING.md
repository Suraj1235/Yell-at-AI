# Licensing

The requested business model is:

- free source access and use for individuals, students, academics, and noncommercial research
- paid license required for enterprises, commercial use, revenue-generating use, and profitable products

That model is source-available noncommercial. It is not OSI open source, because OSI licenses cannot restrict commercial use.

## Current License Structure

- `LICENSE`: noncommercial source license for permitted users.
- `COMMERCIAL-LICENSE.md`: placeholder terms for paid commercial licensing.
- `CONTRIBUTOR-LICENSE-AGREEMENT.md`: contributor grant needed if the project owner wants to dual-license contributed code commercially.

## Practical Guidance

- Keep runtime dependencies permissive and compatible.
- Do not accept substantial external contributions without a signed contributor agreement.
- Keep generated fixtures and docs under the same noncommercial terms unless explicitly separated.
- Before selling enterprise licenses, have counsel review the license text and contributor process.

This repository is prepared for the model, but this is not legal advice.
