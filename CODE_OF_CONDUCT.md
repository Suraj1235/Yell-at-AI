# Code Of Conduct

Be respectful, specific, and constructive. Do not harass, threaten, demean, or exclude people.

This project touches voice, intent, privacy, and accessibility. Treat user data and user interpretation with care. Avoid claims that the software can diagnose emotion, mental state, truthfulness, or intent with certainty.

Maintainers may remove comments, issues, pull requests, or contributors that violate these expectations.
